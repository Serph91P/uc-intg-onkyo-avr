# Select Dirac

As from v0.9.3 this integration offers a 'select' entity for Dirac.

![](./../screenshots/select.png)

This entity will offer a drop down of Dirac options `Off`, `Slot 1`, `Slot 2`, `Slot 3`.

It also acts as a Sensor, showing the current Dirac setting.

Instead of using the Selector, you could also use simple commands in your activities.
- DIRAC_OFF
- DIRAC_SLOT1
- DIRAC_SLOT2
- DIRAC_SLOT3

If not needed, you can disable this Select entity during (re)configuration of the integration, a reboot of your remote is needed to see the effect:

![](./../screenshots/select-dirac.png)
